# DigiDesk documentation

DigiDesk is Wiom's employee operations application. This repository owns its
product contracts, implementation, runtime configuration, and operating
procedures.

| Need | Canonical source |
| --- | --- |
| Intended product and safety behavior | `openspec/specs/` |
| Product surface and known conformance debt | `product/surface.md` |
| Runtime architecture and data ownership | `architecture/runtime.md` |
| Local setup and verification | `runbooks/local-development.md` |
| Debugging and bounded production inspection | `runbooks/debugging.md` |
| Deployment procedure and safeguards | `runbooks/deployment.md` |
| Credential names and provider identities | `reference/runtime-configuration.md` |

`AGENTS.md` and this index route to durable authority; they do not replace the
accepted specifications. Historical commits and deployment metadata are
evidence, not current operating truth.
